# Inventario de repuestos

Aplicación de inventario con frontend web y base SQLite portable.

## Requisitos

- Node.js 18+

## Instalación

```bash
npm install
```

## Ejecutar

```bash
npm start
```

La app quedará disponible en:

```text
http://localhost:3000
```

El archivo SQLite se crea automáticamente en la carpeta `data/inventario.db`.
